# Sistema de Control de Estación de Metrovía - Grupo 6
## Descripción del Proyecto:
El proyecto simula un sistema de administración de una estación de Metrovía en java. Su objetivo es resolver la principal problematica de la metrovía guayaquileña actual, las aglomeraciones. 
Se utiliza un sistema de alertas para indicar si la estación esta llena, además de mostrar la cantidad exacta de personas que hay en la estación y en los buses.
Además el trabajador puede administrar de mejor manera el anden, registrando las personas que entran, los buses que pasan y cuantas personas suben al bus.
El administrador tiene acceso en todo momento al registro de los buses que pasaron y del dinero recaudado. 

## Tecnologías Usadas
* Se utiliza el lenguaje de programación Java.
* Se utilizan varias opciones dentro de este lenguaje como: Implementación de Herencia, Polimorfismo, Clases abstractas e Interfaces.
* Se utiliza el Entorno de Desarrollo, Apache NetBeans.
* Para el control de versiones y repositorio se utiliza Github.

## Instrucciones de Ejecución:
1. Descargar el código.
2. Abrir el proyecto en Apache NetBeans.
3. Localizar el archivo "Main.java" en el paquete "proyecto_g6".
4. Ejecutar el archivo.
5. Puede cambiar instancias como la de la estación para realizar distintas simulaciones de casos específicos.
6. Interactuar mediante consola ingresando los números correspondientes dependiendo de lo que se quiera realizar.
